📚 Tutorial Interativo

Bem-vindo ao SmartSyncGest

O aplicativo funciona offline. Você pode preencher dados no canteiro sem internet e clicar em sincronizar. Assim que houver conexão, os PDFs são gerados.

🛠️ Guia do Engenheiro/Mestre

  • Fotos: Use o botão de câmera na aba RDO. As imagens são reduzidas automaticamente para não travar seu celular.
  • Assinatura: Assine diretamente na tela usando o dedo. Isso anexa validade jurídica ao PDF.
  • Scanner Interno: Use o scanner no menu lateral para ler o QR Code da obra e ver o histórico interno oculto para o cliente.

⚙️ Guia do Administrador

  • Você tem acesso total. Para gerar QR Codes Públicos para os clientes, acesse o painel web em seu computador.
  • Os relatórios de RNC (Não conformidade) lançados pelos engenheiros aparecerão destacados na aba de gestão.
